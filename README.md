# Practical Concurrent and Parallel Programming 2026

## (PCPP) E2026

In this MSc course, you learn how to write correct and efficient concurrent and parallel software, primarily using Java, on standard shared-memory multicore hardware. The course covers basic mechanisms such as threads, locks and shared memory as well as more advanced mechanisms such as parallel streams for bulk data, and lock-free data structures with compare-and-swap. It covers concepts such as atomicity, safety, liveness and deadlock. It covers how to measure and understand the performance and scalability of parallel programs. It covers methods to find bugs and analyze the correctness of concurrent programs. Also, we will take a look at some of the concurrency mechanisms proposed for other programming languages than Java.
