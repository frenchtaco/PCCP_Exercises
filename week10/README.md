# Lecture 10: Java Functional Programming, Data Streams and Parallel Streams 

Monday 2 November 2026


## Goals

The goals of this lecture are:

* To understand and be able to use Java functional programming. 
* To know when and how to use Java streams for data processing.
* To know when and how to parallelize Java streams.
